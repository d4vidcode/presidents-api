Introducción

Base URL local: http://localhost:3000. Las rutas de datos usan prefijo de idioma y versión:

BASE/api/v1/:lang

Idiomas soportados: en, es. Respuestas de lista: { data, meta }. Detalle: { data }.

Health

GET/health

Estado del servicio y conexión a base de datos.

{ "status": "ok", "timestamp": "...", "uptime": 12.3, "db": { "connected": true } }

Países

GET/api/v1/:lang/countries
GET/api/v1/:lang/countries/:isoCode
GET/api/v1/:lang/countries/:isoCode/presidents

:isoCode en formato ISO (ej. PE).

GET /api/v1/es/countries/PE/presidents

Partidos

GET/api/v1/:lang/parties?country=PE
GET/api/v1/:lang/parties/:code?country=PE

Parámetros: country (opcional, ISO 2-3). :code identificador del partido.

Presidentes

GET/api/v1/:lang/presidents
GET/api/v1/:lang/presidents/:slug

Filtros soportados:

country (ISO), party (código), from (fecha), to (fecha), page (≥1), limit (1-100). 

GET /api/v1/es/presidents?country=PE&party=apra&from=1985-01-01&to=1990-12-31&page=1&limit=20

Errores

Formato consistente para validación y recursos no encontrados:

{
  "error": "Bad Request",
  "message": "Invalid date for \"from\". Expected a valid ISO/date string.",
  "details": [ /* cuando aplica */ ]
}

Códigos comunes: 400 (parámetros/idioma/fechas inválidos), 404 (no encontrado), 500 (error interno), 503 (health degradado).
